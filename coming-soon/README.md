# My Carer Coming Soon

Standalone Next.js app. The page component is `app/page.tsx`; styles are in `app/globals.css`. Images and local fonts are in `public/`. No backend or database is required.

Railway: connect the same repository, set Root Directory to `/coming-soon`, Config File Path to `/coming-soon/railway.json`, Build Command to `npm run build`, and Start Command to `npm start`. Health check: `/`. Railway supplies PORT automatically.

Local: `npm install`, then `npm run dev`. Production: `npm run build`, then `npm start`.
